P3CTeX: LaTeX Document Class for UOC Coursework & Reports

A LaTeX document class (P3CTeX.cls) for Universitat Oberta de Catalunya students across any degree or master's program. Pre-configures official submission layouts, declarative student metadata, tables, figures, and code listings for compilation with standard pdflatex.

•
\documentclass[PAC,default]{P3CTeX} — Continuous Assessment (PAC / PEC / CA) Starts directly on page 1 with subject metadata, table of contents, and the mandatory anti-plagiarism declaration. Blank cover page is disabled per coursework rules.
•
\documentclass[PR,default]{P3CTeX} — Project & Practicum Reports (PR) Generates institutional cover page, table of contents, and list of figures for project deliverables.
•
Modular Extensions: MEM • TFG • CMP • GNT Load MEM for multi-chapter memories (adds \chapter, appendices, LOF/LOT); load TFG for UOC thesis front matter (work card, abstracts, CC license); load CMP for compiler diagrams; load GNT for Gantt charts.

Tables (pxTAB)

Creates LaTeX tables from comma-separated rows. Includes automatic alternating row shading (zebra striping) and multi-page page breaks using longtable and booktabs without manual column width calculations.

Syntax: Comma-separated row values
Row striping: Alternating row background shading
Multipage: Long table pagination with \pxTBLlong*
Backend: Built on longtable and booktabs
View Compiled Table Examples → Package Documentation

How to Install and Compile P3CTeX on Your Machine

100% LOCAL • WORKS WITH MIKTEX & TEX LIVE • ZERO INTERNET NEEDED
1
Download or Clone the Repository Get the document class and packages onto your computer
git clone https://github.com/DidacLL/P3CTeX.git
2
Register in MiKTeX (Windows) Tell MiKTeX where P3CTeX is located and refresh the database
initexmf --register-root="/path/to/P3CTeX" && initexmf --update-fndb
3
Configure TeX Live (Linux & macOS) Point TEXINPUTS to the directory, or link it into your ~/texmf folder
export TEXINPUTS=".:/path/to/P3CTeX//:"
4
Compile Your Document Compile cleanly with standard pdflatex
pdflatex your-submission.tex
