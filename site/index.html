\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Grau en Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {PAC 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

% Profile PAC: Portada desactivada; sumari i declaració de no plagi automàtics.

\subsection{Apartat A}
Resolució del primer apartat del document...

\end{document}

Coursework Superpowers: Specialized Macro Packages

Macros designed specifically for computer science problem sets, so you don't fight with raw LaTeX syntax:

pxTAB DATA TABLES [Showcases →]

Painless Comma-Separated Data Tables

Write tables with comma-separated rows using \pxTable. Features automatic alternating row zebra striping (\oddRow) and multipage support (\pxTBLlong*). Eliminates manual & column counting and cryptic \hline syntax crashes.

\pxTable[style=header]{Mètrica, Valor, Estat}{Temps, 0.42 s, PASS}{Memòria, 18.5 MB, PASS}
pxSRC FIGURE ENGINE [Showcases →]

Resilient Auto-Scaling Figures & Fallbacks

Auto-scales graphics to line width (\pxIMG, \pxIMGpair). If an image file is missing on disk, it displays a calibrated fallback placeholder diagram instead of crashing pdflatex compilation before your deadline.

\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura}[fig:arq]
pxLST CODE LISTINGS [Showcases →]

IDE-Grade Code Listings with Syntax Highlighting

Clean dark syntax highlighting with line numbers and copy buffers (\begin{pxCode}). Pre-configured for Java, Python, C, CUP, JLex, SQL, Bash, R, and YAML.

\begin{pxCode}[language=Java,caption=Lexer.java] public class Lexer { ... } \end{pxCode}
pxCMP COMPILERS & AI [Showcases →]

Compilers, Automata & Search Macros

Native macros for compiler Tombstone diagrams (\pxTombstoneCompile), state transition tables (\pxTransitionTable), parser traces, and $A^*$ search graphs.

\pxTombstoneCompile{CUP}{Parser}{Java} & \pxTransitionTable{...}
