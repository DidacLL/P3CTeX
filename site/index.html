READY TO COMPILE

Minimal Compliant PAC Document

Copy this into your editor and compile with pdflatex. Headers, footers, cover, and declarations appear automatically.

LATEX minimal-pac.tex 
% Instant UOC PAC Skeleton
\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {PAC 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}
% Portada desactivada; sumari i declaració de no plagi segons perfil PAC.

\sectionuoc{Exercici 1}
\subsection{Pregunta A}
Resposta a la primera pregunta de l'activitat d'avaluació contínua.

% Taula de dades mitjançant pxTAB (sintaxi per comes)
\pxTable[style=header]{Mètrica, Valor Mesurat, Estat}{Temps de compilació, 0.42 s, PASS}{Consum de memòria, 18.5 MB, PASS}

% Inclusió resilient de figura amb pxSRC (crea placeholder si la imatge no existeix)
\pxIMG[0.8\linewidth]{img/pipeline}{Pipeline del compilador proposat}[fig:pipeline]
\end{document}
WORKFLOW ARCHITECTURE

How to Structure Your Semester

Pick the approach that matches your work habits:

Mode A: Fast One-Off Document

Everything in a single .tex file. Ideal for urgent last-minute deliveries, quick homework, or sharing a self-contained file with a project partner. Zero folder hierarchy required.

See standalone tutorial →

Mode B: The Semester Master Template

Set up your student data once in SharedPreamble.tex at the start of the semester. For every new PAC or PR, simply duplicate the folder, call \LoadPreamble{PAC1}{Nom}, and start typing answers.
