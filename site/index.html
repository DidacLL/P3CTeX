PEC.TeX // P3CTeX

Standardized LaTeX document class and modular packages for UOC coursework.

P3CTeX standardizes LaTeX documents for Computer Engineering studies at Universitat Oberta de Catalunya (UOC). It configures Arev typography, page geometry, running headers, covers, and mandatory anti-plagiarism declarations through class options, with built-in macros for data tables, source code listings, and computer science diagrams.

One class. Three deliverable workflows.

P3CTeX adapts page layout, covers, and tables of contents through class options:

PAC (Continuous Assessment)

Standard deliverable for continuous assessment (PAC / PEC / CA). Starts directly on page 1 with subject metadata and mandatory anti-plagiarism pledge—no blank cover page as required by UOC coursework rules.

COVER PAGE Disabled (Starts on page 1)
TABLE OF CONTENTS Automatic with plagiarism pledge
PAGE GEOMETRY Compact margins, Arev typography
LANGUAGE Catalan (cat) / Spanish (es) / English (en)
AUTOMATIC DELIVERABLE ANATOMY
  • Header banner with student ID, grade, and subject code
  • Official UOC anti-plagiarism statement embedded inline
  • Running headers with automatic page numbering
LATEX SKELETON minimal-uoc.tex 
% Minimal P3CTeX PAC Continuous Assessment Skeleton
\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Grau en Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {PAC 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}
% Profile PAC: Portada desactivada; sumari i declaració de no plagi automàtics.

\sectionuoc{Exercici 1}
\subsection{Apartat A}
Resolució del primer apartat del document...

% Taula declarativa per comes amb pxTAB:
\pxTable[style=header]{Mètrica, Valor Mesurat, Estat}{Temps d'execució, 0.42 s, PASS}{Memòria consumida, 18.5 MB, PASS}

% Inclusió resilient de figura amb pxSRC:
\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura proposada}[fig:arq]
\end{document}

02 // COURSEWORK TOOLKIT

Macros tailored for computer science coursework.

Built-in toolkits that eliminate common LaTeX headaches across your semester assignments:

TABLES pxTAB

Data Tables Without the Pain

Skip manual column width math, ampersands, and hlines. Write clean comma-separated rows with \pxTable. Features automatic alternating row zebra striping and multipage support.

\pxTable[style=header]{Mètrica, Valor, Estat}{Temps, 0.42 s, PASS}{Memòria, 18.5 MB, PASS}
View table examples →
FIGURES pxSRC

Resilient Figures & Fallbacks

Auto-scales images to text width with \pxIMG. If a graphic file path is missing on disk, P3CTeX prints a calibrated placeholder diagram instead of halting compilation right before your deadline.

\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama d'arquitectura}[fig:arq]
View figure examples →
CODE pxLST

Syntax-Highlighted Code Blocks

Formatted code blocks with line numbers using \begin{pxCode}. Pre-configured for Java, Python, C, SQL, Bash, R, and YAML without requiring external pygments installations.

\begin{pxCode}[language=Java,caption=Lexer.java] ... \end{pxCode}
View code examples →
DIAGRAMS pxCMP

Compilers & Automata Tools

Dedicated macros for Computer Science courses: Tombstone compiler diagrams (\pxTombstoneCompile), finite state automata transition tables, and parser trees without manual TikZ coding.

\pxTombstoneCompile{CUP}{Parser}{Java} & \pxTransitionTable{...}

03 // GETTING STARTED

Three-step local installation.

Works with standard pdflatex on MiKTeX (Windows) or TeX Live (Linux, macOS, Windows) and any editor (VS Code, TeXstudio, TeXworks):

01

1. Download P3CTeX Release

Download and extract P3CTeX-vX.Y.Z.zip from GitHub Releases, or clone the repository directly using git:

git clone https://github.com/DidacLL/P3CTeX.git
02

2. Register with Your TeX Distribution

Tell your TeX engine where P3CTeX lives so any document on your computer can find \documentclass{P3CTeX}:

# MiKTeX (GUI): Settings → Directories → Add folder → Refresh FNDB
# MiKTeX (CLI): initexmf --register-root="/path/to/P3CTeX" && initexmf --update-fndb
# TeX Live: Add folder to TEXMFHOME or export TEXINPUTS="/path/to/P3CTeX//:"
03

3. Compile with pdflatex

Open your document in VS Code (with LaTeX Workshop) or TeXstudio and hit compile, or run from terminal:

pdflatex your-document.tex
