PEC.TeX // P3CTeX

P3CTeX is an open-source LaTeX document class and modular toolkit based on official UOC styles. It standardizes university typography (Arev), geometry, covers, tables, and CS diagrams into a single line of code.

// 01 · DELIVERY PROFILES

One class. Three deliverable types.

You don't need different templates for different courses. P3CTeX.cls adapts automatically to your submission type via simple class options:

Profile Option Coursework Context Cover Page Table of Contents Authorship / Plagiarism Default Language
[PAC] Continuous Assessment (UOC) Disabled (No cover) Enabled (Automatic) Inline Statement Catalan (cat)
[PEC] Evaluación Continua Disabled (No cover) Enabled (Automatic) Inline Statement Spanish (es)
[CA] Continuous Assessment Disabled (No cover) Enabled (Automatic) Inline Statement English (en)
[PR] Practicum / Project Report Enabled (Formal Institutional) Enabled (Full TOC) Printed on Cover Catalan (cat)
[TFG,MEM] Bachelor Thesis Memory Enabled (Tribunal Sheet) Enabled (Chapters & Appendices) CC License Block Bilingual (cat/en)
PROFILE OPTION: [PAC] / [PEC] / [CA] \documentclass[PAC]{P3CTeX}

Continuous Assessment Coursework

Designed for compact assignments. Suppresses the formal cover page, automatically builds the table of contents, and prints the mandatory UOC anti-plagiarism declaration at the beginning of the submission.

PROFILE OPTION: [PR] \documentclass[PR]{P3CTeX}

Practicum & Laboratory Reports

Designed for extensive semester deliverables. Automatically creates the formal institutional UOC cover page with subject details, author metadata, full table of contents, and list of figures.

PROFILE OPTION: [TFG,MEM] \documentclass[TFG,MEM]{P3CTeX}

Bachelor's Thesis Memory

Designed for final degree projects (Treball de Final de Grau). Integrates the official evaluation tribunal sheet, bilingual abstracts, Creative Commons licensing block, and formal memory chapter organization.

// 02 · MINIMAL WORKING SKELETON

Copy, paste, and compile.

Define your student and subject info once in \PECTeXconfig{ data = { ... } }. The engine routes values to headers, footers, covers, and PDF properties:

LATEX minimal-uoc.tex 
% Minimal P3CTeX Document Skeleton
\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Grau en Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {PAC 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}
% Profile PAC: Portada desactivada; sumari i declaració de no plagi automàtics.

\sectionuoc{Exercici 1}
\subsection{Apartat A}
Resolució del primer apartat del document...

% Taula declarativa per comes amb pxTAB (inclosa al paquet default)
\pxTable[style=header]{Mètrica, Valor Mesurat, Estat}{Temps d'execució, 0.42 s, PASS}{Memòria consumida, 18.5 MB, PASS}

% Inclusió resilient de figura amb pxSRC (crea placeholder si la imatge no existeix)
\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura proposada}[fig:arq]
\end{document}
// 03 · BUILT-IN TOOLKITS

Batteries included for technical coursework.

Loading default or CMP activates pre-configured macros for common student authoring tasks:

MODULE: pxTAB Showcases →

Painless Data Tables

Write tables with comma-separated rows (\pxTable). Includes zebra striping (\oddRow) and multipage support (\pxTBLlong*). Eliminates manual & column counting.

MODULE: pxSRC Showcases →

Resilient Figures

Auto-scales graphics (\pxIMG, \pxIMGpair). If an image file is missing, it displays a calibrated fallback placeholder instead of crashing pdflatex.

MODULE: pxLST Showcases →

IDE Code Blocks

Dark-themed syntax highlighting with line numbers (\begin{pxCode}). Pre-configured for Java, Python, C, CUP, JLex, SQL, Bash, R, and YAML.

MODULE: pxCMP Showcases →

Compilers & Automata

Native macros for compiler Tombstone diagrams (\pxTombstoneCompile), state transition tables (\pxTransitionTable), traces, and $A^*$ search graphs.
