Minimal Assessment Skeleton

Instant, compilable coursework.

A complete, self-contained assessment document ready to compile with pdflatex in your local environment.

LATEX minimal-pac.tex
% Instant UOC PAC Skeleton
\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Dídac Llorens},
    grade          = {Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {Repte 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}
\section{Exercici 1}
\subsection{Pregunta A}
Resposta a la primera pregunta de l'activitat d'avaluació contínua.

% Taula de dades mitjançant pxTAB (sintaxi per comes)
\pxTable[style=header]{Mètrica, Valor Mesurat, Estat}{Temps de compilació, 0.42 s, PASS}{Consum de memòria, 18.5 MB, PASS}

% Inclusió resilient de figura amb pxSRC (crea placeholder si la imatge no existeix)
\pxIMG[0.8\linewidth]{img/pipeline}{Pipeline del compilador proposat}[fig:pipeline]
\end{document}
WORKFLOW MODELS

How P3CTeX Fits Your Coursework

Depending on whether you want a fast standalone deliverable or a centralized multi-assignment workflow across your semester:

Model A: Self-Contained Document

Everything in a single .tex file. Ideal for urgent deliveries, single PACs, or when sharing a single self-sufficient file with classmates. Requires zero directory hierarchy.

See standalone PAC tutorial →

Model B: Shared-Preamble Hierarchy

The official UOC template pattern. SharedPreamble.tex holds your personal identity and global macros; each subject has its own SubjectPreamble.tex, and your assignments simply invoke \LoadPreamble{PAC1}{...}.

Explore shared preambles →
ARSENAL

Modular Package Capabilities

Every module is decoupled. Use them automatically via default or load individual packages independently inside your documents:

pxSRC — Resilient Figures & Image Lists

Safe image inclusion that replaces missing files with calibrated dimensioned placeholders. Includes \pxIMGList for automated batch caption sequences without manual repetition.

View pxSRC showcase →

pxTAB — List-Driven Tables & Multipage

Build formatted tables from comma-separated rows without raw tabular markup. Includes built-in branded presets (p3c-data, p3c-rubric) and \pxTBLlong for multipage tables.

View pxTAB showcase →

pxLST — Professional Code Listings

Syntax-highlighted Darcula-style framed code boxes for 16 languages (Java, Python, C, Bash, SQL, JLex, CUP, Prolog, YAML, and Pseudocode) with side-note annotation panels.

View pxLST showcase →

pxCMP — Compilers & Automata Diagrams

Declarative macros for compiler Tombstone T-diagrams, DFA/NFA state transition tables, validation traces, heuristic search graphs ($A^*$), decision trees, and neural networks.

View pxCMP showcase →
