Onboarding in 60 Seconds: Minimal PAC Assessment

The standard UOC semester workflow requires zero external boilerplate. Copy the template below and compile with any standard LaTeX distribution:

LaTeX PAC1_Minimal.tex 
\documentclass[PAC,default]{P3CTeX}

%% Document Metadata Configuration
\PECTeXconfig{
  data = {
    student        = {Nom de l'Estudiant},
    grade          = {Grau d'Enginyeria Informàtica},
    subj-fullname  = {Enginyeria del Software},
    subj-shortname = {ES},
    subj-code      = {05.597},
    ca-fullname    = {PAC 1: Especificació de Requisits},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}

\section{Exercici 1: Model Conceptual}
En aquest apartat es descriu l'arquitectura proposada per a la solució...

\section{Exercici 2: Taula d'Avaluació}
\pxTable[style=header]{Component, Estat, Prioritat}{
  API Backend, Completat, Alta}{
  Interfície Web, En curs, Mitjana}{
  Base de Dades, Pendent, Crítica}

\end{document}
