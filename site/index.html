DOCUMENT CLASS ARCHITECTURE

One unified class. Simple delivery profiles.

In standard LaTeX, students often copy bloated 200-line preambles between semesters. P3CTeX centralizes page geometry, Arev typography, headers, footers, and official UOC formatting into a single class: P3CTeX.cls.

The options you pass to \documentclass[...] are simple delivery profiles that adjust the cover page, table of contents, and language. All packages and tools remain fully available across every profile:

PROFILE: PAC / PEC / CA

Continuous Assessment

Designed for compact coursework assignments (PAC in Catalan, PEC in Spanish, CA in English). Suppresses the formal cover page and automatically prints the table of contents and the mandatory university anti-plagiarism declaration.

\documentclass[PAC]{P3CTeX}
PROFILE: PR

Laboratory & Practicum Reports

Designed for extensive semester projects and practicum reports. Automatically formats the formal institutional UOC cover page with subject details, author metadata, table of contents, and figure listings.

\documentclass[PR]{P3CTeX}
PROFILE: TFG / MEM

Bachelor's Thesis Memory

Designed for final degree projects (Treball de Final de Grau). Integrates the official evaluation tribunal sheet, bilingual abstracts, Creative Commons licensing block, and formal memory chapter organization.

\documentclass[TFG,MEM]{P3CTeX}
READY TO COMPILE

Minimal Working Skeleton

Metadata is defined declaratively through \PECTeXconfig{ data = { ... } }. The engine automatically routes these values to page headers, footers, cover pages, and PDF properties:

LATEX minimal-uoc.tex 
% Minimal P3CTeX Document Skeleton
\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Grau en Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {PAC 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}
% Profile PAC: Portada desactivada; sumari i declaració de no plagi automàtics.

\sectionuoc{Exercici 1}
\subsection{Apartat A}
Resolució del primer apartat del document...

% Taula declarativa per comes amb pxTAB (inclosa al paquet default)
\pxTable[style=header]{Mètrica, Valor Mesurat, Estat}{Temps d'execució, 0.42 s, PASS}{Memòria consumida, 18.5 MB, PASS}

% Inclusió resilient de figura amb pxSRC (crea placeholder si la imatge no existeix)
\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura proposada}[fig:arq]
\end{document}
MODULAR TOOLKITS

Macros for the challenging parts of technical coursework.

P3CTeX bundles specialized toolkits designed to eliminate the most time-consuming LaTeX tasks in technical and scientific coursework:

TOOLKIT: PXTAB

Painless Data Tables

Standard LaTeX tables require manually counting & columns and handling line wraps. pxTAB provides declarative comma-separated syntax (\pxTable), pre-styled headers, alternating zebra striping (\headRow, \oddRow), and multipage support (\pxTBLlong*).

Inspect table showcases →
TOOLKIT: PXSRC

Figures with Fallback Safety

In reports, missing image paths crash pdflatex with fatal errors. \pxIMG scales graphics automatically and renders a calibrated fallback placeholder if the file is missing, keeping compilation uninterrupted. Also supports \pxIMGpair and sequential lists (\pxIMGList).

Inspect figure showcases →
TOOLKIT: PXLST

IDE Code Listings

Typeset source code with syntax highlighting, line numbers, and caption labels (\begin{pxCode}, \begin{CodeBox}). Pre-configured for Java, Python, C, Bash, R, SQL, CUP, JLex, Prolog, YAML, and pseudocode.

Inspect code showcases →
TOOLKIT: PXCMP

Compilers, Automata & AI

Dedicated macros for Computer Science topics: compiler Tombstone T-diagrams (\pxTombstoneCompile), finite state automata transition tables (\pxTransitionTable), word recognition traces (\pxAutomatonTrace), $A^*$ search graphs (\pxGraph), decision trees, and confusion matrices.

SETUP & DISTRIBUTION

Install once. Use across all semesters.

You don't need Git or package managers to use P3CTeX. It is distributed as a clean TeX directory tree:

  1. Download the Release: Download P3CTeX-vX.Y.Z.zip from GitHub Releases and extract it to a permanent folder on your computer (e.g., C:\LaTeX\P3CTeX or ~/texmf/p3ctex).
  2. Register in your TeX Distribution: In the MiKTeX Console (or TeX Live Manager), add the extracted root directory to your TeX directories list, then click Refresh Filename Database (FNDB).
  3. Compile from anywhere: In your preferred editor (VS Code, TeXstudio, TeXworks), write \documentclass[PAC]{P3CTeX} in any document and compile with pdflatex. For Overleaf, simply drop the repository files into your project folder.
