PEC.TeX // P3CTeX

Official LaTeX document class and modular packages for UOC Computer Engineering.

P3CTeX is an open-source LaTeX repository based on official styles defined by the Universitat Oberta de Catalunya (UOC). It standardizes university typography (Arev), page geometry, covers, mandatory anti-plagiarism declarations, and computer science coursework macros into a unified document class.

Declarative configuration.

Student and subject metadata is defined once in \PECTeXconfig. The class routes values to document headers, footers, covers, and PDF metadata automatically:

[INPUT SOURCE] document.tex 
\documentclass[PAC,default]{P3CTeX}

\PECTeXconfig{
  data = {
    student       = {Nom i Cognoms},
    grade         = {Grau en Enginyeria Informàtica},
    subj-fullname = {Compiladors i Llenguatges},
    ca-fullname   = {PAC 1: Anàlisi Lèxica}
  }
}

\begin{document}
\sectionuoc{Exercici 1}
Resolució de l'exercici...

% Taula declarativa per comes amb pxTAB:
\pxTable[style=header]{Mètrica, Resultat}{Temps, 0.42 s}{Memòria, 18.5 MB}
\end{document}

Delivery profiles.

P3CTeX adapts document layout, covers, and table of contents through class options:

Profile Option Deliverable Type Cover Page Table of Contents Plagiarism Pledge Default Language
[PAC] Continuous Assessment (UOC) Disabled (No cover) Automatic Inline Statement Catalan (cat)
[PEC] Evaluación Continua Disabled (No cover) Automatic Inline Statement Spanish (es)
[CA] Continuous Assessment Disabled (No cover) Automatic Inline Statement English (en)
[PR] Practicum & Lab Projects Formal Institutional Cover Full TOC & Figures Printed on Cover Catalan (cat)
[TFG,MEM] Bachelor Thesis Memory Official Tribunal Sheet Chapters & Appendices CC License Block Bilingual (cat/en)
MODE: PAC (Continuous Assessment) | COVER: Disabled (No cover) | TOC: Enabled (Automatic) | LANG: Catalan (cat)
LATEX minimal-uoc.tex 
% Minimal P3CTeX PAC Continuous Assessment Skeleton
\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Grau en Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {PAC 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}
% Profile PAC: Portada desactivada; sumari i declaració de no plagi automàtics.

\sectionuoc{Exercici 1}
\subsection{Apartat A}
Resolució del primer apartat del document...

% Taula declarativa per comes amb pxTAB:

% Inclusió resilient de figura amb pxSRC:
\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura proposada}[fig:arq]
\end{document}
03 //

Package suite & macros.

P3CTeX modular libraries provide specialized macros for technical coursework:

TABLES pxTAB.sty [Showcases →]

Data Tables (pxTAB)

Create tables by listing rows separated by commas with \pxTable. Includes automatic alternating row shading (\oddRow) and multipage table support (\pxTBLlong*) without manual column width calculations.

\pxTable[style=header]{Mètrica, Valor, Estat}{Temps, 0.42 s, PASS}{Memòria, 18.5 MB, PASS}
FIGURES pxSRC.sty [Showcases →]

Figure Scaling & Fallbacks (pxSRC)

Auto-scales images to text width using \pxIMG. If a graphic file path is not found on disk, it displays a calibrated placeholder diagram instead of halting compilation.

\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura}[fig:arq]
CODE pxLST.sty [Showcases →]

Code Listings (pxLST)

Syntax-highlighted code blocks with line numbers (\begin{pxCode}). Pre-configured for Java, Python, C, SQL, Bash, R, and YAML.

\begin{pxCode}[language=Java,caption=Lexer.java] public class Lexer { ... } \end{pxCode}
DIAGRAMS pxCMP.sty [Showcases →]

Automata & Compiler Diagrams (pxCMP)

Macros for compiler Tombstone compilation diagrams (\pxTombstoneCompile), state transition tables (\pxTransitionTable), parser traces, and $A^*$ search graphs.

\pxTombstoneCompile{CUP}{Parser}{Java} & \pxTransitionTable{...}
04 //

Installation & local setup.

Recommended configuration: MiKTeX (or TeX Live) with pdflatex and an IDE (VS Code with LaTeX Workshop, TeXstudio, or TeXworks).

01

1. Download P3CTeX Release

[Releases →]

Download and extract P3CTeX-vX.Y.Z.zip from GitHub Releases, or clone the repository directly using git: git clone https://github.com/DidacLL/P3CTeX.git.

02

2. Register with TeX Distribution

[Setup Details →]

In MiKTeX Console, open Settings → Directories → Add, select the extracted folder (the directory containing tex/), and refresh the file name database (FNDB). On command line: initexmf --register-root="/path/to/P3CTeX" && initexmf --update-fndb. For TeX Live, add the directory to your TEXMFHOME or set TEXINPUTS.

03

3. Compile with pdflatex

Verify installation by compiling your document from terminal or IDE: pdflatex your-document.tex.
