P3CTeX: LaTeX Suite for UOC Coursework & Projects

P3CTeX is an open-source LaTeX document class (P3CTeX.cls) and macro suite for Universitat Oberta de Catalunya (UOC). It sets up official university margins, geometry, Babel multilingual declarations, student metadata (\PECTeXconfig), and specialized engineering macros for 100% offline compilation using standard pdflatex.

Step 1: Document Class & Profiles

CORE SETUP

Every P3CTeX document begins with \documentclass[<profile>,default]{P3CTeX}. The profile controls the document's structure, primarily whether it includes an institutional cover page or starts immediately on page 1.

// PROFILE OPTIONS REFERENCE:
PAC / PEC / CAContinuous assessment (starts directly on page 1, anti-plagiarism pledge, no blank cover). Catalan (PAC), Spanish (PEC), or English (CA).
PRPracticum / Lab report (adds institutional UOC cover page and table of contents).
MEMMulti-chapter technical memory with \chapter support and appendix numbering.
TFGFinal Degree Project with official UOC academic work card and bilingual abstract.
💡 Why PAC vs PR? UOC grading rubrics for continuous assessment (PAC) penalize blank cover pages because teachers grade hundreds of papers. PAC puts your name and anti-plagiarism pledge directly at the top of page 1. For term projects (PR), switch to [PR] to generate the graphic cover.

Tables (pxTAB)

booktabs + longtable

Creates LaTeX tables from comma-separated rows. Includes automatic alternating row shading (zebra striping) and multi-page page breaks using longtable and booktabs without manual column width calculations.

// COMMAND REFERENCE & SIGNATURES:
Command / Syntax Purpose & Parameters
\pxTable[style=...]{head}{row1}{row2} Creates a comma-separated table with automatic column sizing.
\pxTBLlong*[opts]{head}{rows...} Multi-page table that repeats headers across page breaks.
styles: header | striped | boxed | grid Visual presentation themes without requiring TikZ.
Syntax: Comma-separated row values
Row striping: Alternating row background shading
Multipage: Long table pagination with \pxTBLlong*
Backend: Built on longtable and booktabs

VERIFIED CODE EXAMPLE: 
% Create a complete table with comma-separated values:
\pxTable[style=header]
  {Mètrica / Paràmetre, Valor Mesurat, Llindar, Estat}
  {Temps d'execució, 0.42 s, < 1.00 s, PASS}
  {Consum de Memòria, 18.5 MB, < 64.0 MB, PASS}
  {Complexitat Temporal, O(n log n), O(n^2), OPTIMAL}
  {Taxa d'encert (Cache), 96.8 %, > 90.0 %, PASS}
  {Cobertura de Tests, 94.2 %, > 80.0 %, PASS}
// PARAMETER & SYNTAX BREAKDOWN:
  • [style=header]: High-contrast header row with subtle separator borders.
  • {Mètrica, Valor, Estat}: Header row with comma-separated column titles.
  • {row...}: Subsequent argument braces form table rows automatically.
  • Zero manual width arithmetic needed; columns fit content proportionally.

How to Install and Compile P3CTeX Locally

100% LOCAL • MIKTEX & TEX LIVE COMPATIBLE • ZERO INTERNET NEEDED
1
Step 1: Download or Clone Repository Get the document class and packages onto your machine
git clone https://github.com/DidacLL/P3CTeX.git
2
Step 2: Windows MiKTeX Root Registration Register directory in MiKTeX settings and refresh filename database
initexmf --register-root="C:\path\to\P3CTeX" && initexmf --update-fndb
3
Step 3: Linux & macOS TeX Live Environment Point TEXINPUTS to directory or symlink into ~/texmf
export TEXINPUTS=".:/path/to/P3CTeX//:"
4
Step 4: Compile Cleanly with pdflatex Run standard compilation from your document folder
pdflatex your-submission.tex
// COMMON TERMINAL COMPILATION FIXES:
! LaTeX Error: File 'P3CTeX.cls' not found.Ensure P3CTeX is in your local folder or run initexmf --update-fndb.
! Font \arev... not found.Install the Arev Sans font package or update font maps via initexmf --mkmaps.
! Undefined control sequence.Ensure standard pdflatex is used with all bundled px*.sty files present.
💡 Zero-Setup Portable Method

Don't want to register system roots? Simply copy P3CTeX.cls and the px*.sty files directly into your coursework folder. pdflatex will automatically find and load them with zero configuration!
