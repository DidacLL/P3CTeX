% Minimal P3CTeX PAC Continuous Assessment Skeleton
\documentclass[PAC,default]{P3CTeX}

% Declarative UOC Student & Subject Metadata
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Grau en Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {PAC 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

\begin{document}
% Profile PAC: Portada desactivada; sumari i declaració de no plagi automàtics.

\sectionuoc{Exercici 1}
\subsection{Apartat A}
Resolució del primer apartat del document...

% Taula declarativa per comes (sense comptar columnes manualment)
\pxTable[style=header]{Mètrica, Valor Mesurat, Estat}{Temps d'execució, 0.42 s, PASS}{Memòria consumida, 18.5 MB, PASS}

% Inclusió resilient de figura (mai fa caure la compilació)
\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura proposada}[fig:arq]
\end{document}
03 //

Coursework Superpowers: What it does for you.

Common headaches in computer engineering coursework, solved with simple built-in macros:

TABLES NO MORE & & \\ \hline [See Examples →]

Effortless Comma-Separated Data Tables

Write tables by simply listing rows separated by commas with \pxTable. Includes automatic alternating row zebra striping (\oddRow) and multi-page continuation for long data sets. You will never spend 20 minutes counting & columns again.

\pxTable[style=header]{Mètrica, Valor, Estat}{Temps, 0.42 s, PASS}{Memòria, 18.5 MB, PASS}
FIGURES CRASH-PROOF IMAGES [See Examples →]

Auto-Scaled Figures That Never Overflow

Graphics automatically scale to page width (\pxIMG). If an image file path is accidentally missing on your machine, it displays a clean calibrated placeholder diagram instead of crashing pdflatex right before your submission deadline.

\pxIMG[0.8\linewidth]{img/arquitectura}{Diagrama de l'arquitectura}[fig:arq]
CODE SYNTAX HIGHLIGHTING [See Examples →]

Clean Dark-Themed Code Blocks

Drop your code straight into formatted listings with line numbers and IDE-grade styling. Pre-configured for Java, Python, C, SQL, Bash, R, and YAML.

\begin{pxCode}[language=Java,caption=Lexer.java] public class Lexer { ... } \end{pxCode}
DIAGRAMS COMPILERS & AUTOMATA [See Examples →]

Compiler Tombstones & State Machines

Native one-liners for computer science subjects: compiler Tombstone compilation diagrams (\pxTombstoneCompile), finite automata state transition matrices (\pxTransitionTable), parser traces, and $A^*$ search graphs.

\pxTombstoneCompile{CUP}{Parser}{Java} & \pxTransitionTable{...}
