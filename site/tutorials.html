01 / BOOTSTRAP

Installation & Environment Setup

P3CTeX is distributed as a packaged TeX tree. You do not need to clone Git repositories to use it in your daily coursework. Once registered in your TeX distribution, \documentclass{P3CTeX} is available system-wide across all your assignments.

  1. Install MiKTeX or TeX Live: Install a standard LaTeX distribution on your computer (MiKTeX on Windows, or TeX Live on Linux/macOS). In MiKTeX, enable "Install missing packages on-the-fly".
  2. Download the Release Package: Download P3CTeX-vX.Y.Z.zip from GitHub Releases and extract it to a permanent folder on your system (e.g. C:\LaTeX\P3CTeX or ~/texmf/p3ctex).
  3. Register with your TeX Distribution (One-Time Step):
    • MiKTeX: Open MiKTeX Console → Settings → Directories tab → Click Add → Select the extracted P3CTeX folder → Click Tasks → Refresh file name database (FNDB).
    • TeX Live: Place the files into your personal TEXMFHOME directory or set TEXINPUTS=".:/path/to/p3ctex//:" in your shell.
    • Coursework Directory: Alternatively, you can simply extract the release ZIP directly into your assignment folder next to your .tex file.

Configuring VS Code & LaTeX Workshop for One-Click Compilation

In VS Code with the LaTeX Workshop extension, use this clean build recipe in your settings.json:

JSON settings.json
{
  "latex-workshop.latex.tools": [
    {
      "name": "pdflatex-p3ctex",
      "command": "pdflatex",
      "args": [
        "-synctex=1",
        "-interaction=nonstopmode",
        "-file-line-error",
        "%DOC%"
      ]
    }
  ]
}
02 / PREAMBLE

Preamble Anatomy & UOC Metadata

A compliant P3CTeX document begins with \documentclass[options]{P3CTeX} and a single declarative metadata configuration block. This guarantees that all header ribbons, footers, cover sheets, and title bars match official university standards.

Frequently Used Document Class Options

  • PAC: Catalan continuous assessment profile (no cover, with table of contents and authorship declaration).
  • PEC: Spanish continuous assessment profile (no cover, with TOC and declaration).
  • PR: Practicum / Project laboratory profile (formal cover, TOC, and figures list).
  • TFG / MEM: Bachelor Thesis / Degree Memory profile (tribunal page, multilingual abstracts, and Creative Commons license).
  • CAT, ES, EN: Document language selection.
  • default: Automatically loads common modules: pxPRP, pxUML, pxSRC, pxTAB, pxLST. Extra \usepackage calls are not needed!
  • CMP: Compilers, automata, search graphs, and AI diagrams module.
  • GNT: Gantt charts planning module.
LATEX Minimal Compliant Preamble
% Document class with PAC profile and default modules loaded
\documentclass[PAC,default]{P3CTeX}

% Academic & Student Identification Data
\PECTeXconfig{
  data = {
    student        = {Dídac Llorens},
    grade          = {Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {Repte 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}

03 / ARCHITECTURE

The Official Shared-Preamble Pattern

In real university coursework, typing student metadata and subject codes across 4 PACs and 2 PRs per semester is tedious and error-prone. P3CTeX provides a battle-tested 3-tier hierarchy that separates global identity, subject configuration, and assignment content.

The Three-Tier Directory Structure

  1. SharedPreamble.tex (Global): Lives in the root coursework folder. Sets your student name, degree (Enginyeria Informàtica), non-plagiarism declaration, and personal macros (such as \itembf).
  2. MINPreamble.tex (Subject Level): Lives in each subject folder. Sets subject name, code, bibliography, and defines \LoadPreamble{PAC1}{Nom de l'activitat}.
  3. PAC1/MinimalTemplatePAC.tex (Assignment Body): The actual file you write! Only contains two lines of preamble setup, followed by \begin{document} and your answers.
LATEX PAC1/MinimalTemplatePAC.tex
% Load subject preamble relative to this file
\input{../MINPreamble.tex}

% Inject assignment identifier and full activity title
\LoadPreamble{PAC1}{Anàlisi Lèxica i Sintàctica}

\begin{document}
\section{Exercici 1}
\subsection{Pregunta A}
La resposta a l'exercici es redacta directament aquí.
\end{document}
04 / WORKFLOW

PAC Continuous Assessment Workflow

Continuous assessment submissions require clear answers, structured tables, and illustrative diagrams. With P3CTeX modules loaded via default, you have high-level macros for every task:

1. Tables without tabular boilerplate (pxTAB)

Build tables using comma-separated rows. No manual \hline or column coordinate counting:

LATEX Comma-Separated Table
\pxTable[style=header]{
  Component, Estat, Mètrica
}{
  Lexer (JLex), Complet, 120 tokens/s
}{
  Parser (CUP), Complet, 45 regles
}{
  Generador JVM, Pendent, 0 instruccions
}

2. Resilient figures that never crash builds (pxSRC)

If an image file is missing while compiling under deadline stress, P3CTeX renders a neat placeholder box preserving layout geometry:

LATEX Safe Figure Inclusion
% Inclusió segura d'imatge amb pxSRC
\pxIMG[0.8\linewidth]{img/pipeline}{Pipeline del Compilador}[fig:pipeline]

% Comparativa de dues imatges de costat
\pxIMGpair[0.45\linewidth]{img/ast_initial}{img/ast_optimized}{Arbre Sintàctic abans i després de l'optimització}[fig:ast-comp]

3. Syntax-highlighted code with side comments (pxLST)

LATEX pxCode Listing
\begin{pxCode}[language=pxJava]{Exemple de Factorial}
public class MathUtils {
    public static long factorial(int n) {
        if (n <= 1) return 1;
        return n * factorial(n - 1);
    }
}
\end{pxCode}
05 / ADVANCED

Laboratory Reports (PR) & Bachelor Theses (TFG)

Large deliverables require formal university covers, multi-chapter memory management, and official assessment criteria.

Practicum Laboratory Reports (\documentclass[PR,default]{P3CTeX})

The PR option automatically generates the full university cover page, table of contents, list of figures, and formatted chapter headers.

Degree Final Theses (\documentclass[TFG,CAT]{P3CTeX})

The TFG and MEM modules provide:

  • Official university tribunal assessment sheet.
  • Multilingual abstract blocks (Catalan, Spanish, English).
  • Creative Commons licensing declaration (CC-BY-SA, CC-BY-NC, etc.).
  • Modular chapter structure using \input{chapters/01_introduction.tex}.
06 / TRIAGE

Emergency Survival Triage (Last-Minute Fixes)

When compiling at 23:45 on deadline night, use these fast triage solutions:

Error: ! LaTeX Error: File 'P3CTeX.cls' not found

Cause: MiKTeX or TeX Live has not indexed the P3CTeX directory in its database.

Quick Fix (30 seconds): Simply copy P3CTeX.cls and the .sty files directly into the same folder as your assignment .tex file. LaTeX always checks the current folder first!

Permanent Fix: Open MiKTeX Console → Tasks → Refresh file name database (FNDB).

Error: ! Undefined control sequence \pxTombstoneCompile

Cause: The compiler and automata module (pxCMP) was not loaded.

Fix: Add CMP to your document class options: \documentclass[CMP,PAC,default]{P3CTeX}.

Error: Package babel Error: Unknown language 'catalan'

Cause: The Catalan hyphenation and language patterns are missing in your TeX distribution.

Fix: Install texlive-lang-spanish / texlive-lang-european in TeX Live, or in MiKTeX Console install package babel-catalan.
