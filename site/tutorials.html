1. TeX Setup & Installation

P3CTeX is designed to work with all major LaTeX distributions that support LaTeX3 / expl3 (TeX Live 2021+, MiKTeX 21+, MacTeX).

WINDOWS (MIKTEX)

Automated Package Retrieval

Install MiKTeX with "Install missing packages on-the-fly: Yes". Clone or copy the P3CTeX repository into your local document directory or register it in your local TeX root (C:\localtexmf\tex\latex\P3CTeX).

LINUX / MACOS (TEX LIVE)

Standard TeX Tree Integration

Install texlive-latex-extra, texlive-science, and texlive-fonts-recommended. Symlink the tex/latex/ directory into ~/texmf/tex/latex/P3CTeX and run texhash.

3. The 3-Tier Shared Preamble Architecture

In production university environments, students often take multiple subjects simultaneously. P3CTeX provides an architectural pattern that separates concerns across three hierarchical files:

TIER 1 · GLOBAL

SharedPreamble.tex

Stores immutable student identity data: legal name, degree program, and personal macro definitions. Shared across all semesters.

TIER 2 · SUBJECT

MINPreamble.tex

Configures course-specific details: subject name, course code, instructor details, and active package bundles (e.g. pxCMP for compilers, pxCALC for electronics).

TIER 3 · ACTIVITY

PAC1.tex / PR1.tex

Contains only the deliverable title, submission date, and exercise solutions. Eliminates copy-pasted configuration errors.

4. PAC Assessment Workflow (Step-by-Step)

Follow these steps to produce an official Continuous Assessment submission:

Step 1: Declare the PAC Document Class & Modules

Place \documentclass[PAC,default,CMP]{P3CTeX} at the top of your document. The PAC preset disables the cover page, sets the language to Catalan, activates the running headers with your activity name, and formats the anti-plagiarism statement automatically.

Step 2: Fill in Document Metadata

Configure your student credentials, subject code, and PAC number in \PECTeXconfig{data={...}}.

Step 3: Author Content with Specialized Modules

Use \section{...} and \subsection{...} for questions. When inserting calculations, use \pxSolve from pxCALC; when showing code, use \begin{pxCode} from pxLST; when drawing state machines, use \pxAutomaton from pxCMP.

5. Project & Practicum Report (PR) Workflow

Major semester deliverables require formal front matter. Specifying [PR] automatically creates a cover page with backtitle and table of contents:

LaTeX PR1_Compiladors.tex 
\documentclass[PR,cat,default,CMP]{P3CTeX}

\PECTeXconfig{
  data = {
    student        = {Alexandre Soler i Puig},
    grade          = {Grau d'Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {CiL},
    subj-code      = {05.602},
    ca-fullname    = {Pràctica 1: Analitzador Sintàctic},
    ca-shortname   = {PR1},
    date           = {\today}
  }
}

\begin{document}

\section{Arquitectura del Compilador}
\pxCompilerModel[title={Diagrama de Blocs del Pipeline}]

\section{Implementació de l'Analitzador Lèxic}
\begin{pxCode}[language=pxJLex]{Tokens Léxics (scanner.flex)}
 "function" { return emitToken(SYM_FUNCTION); }
 [0-9]+      { return emitToken(NUM_LITERAL); }
\end{pxCode}

\end{document}

6. Treball Final de Grau (TFG / MEM) Suite

The TFG suite supports two-tier compilation where deliverables from semester milestones (PR1, PR2) feed directly into the final degree thesis memory (MEM.tex):

\chapter Support

True Chapters in Article Class

Using the MEM option unlocks full \chapter{...} commands, formal chapter page headers, and appendix letter resets without sacrificing P3CTeX layouts.

Region Re-use

\pxMEMsource & \pxMEMinclude

Tag regions in your earlier PR deliverables (e.g. %<*objectius> ... %</objectius>) and include them directly into your final thesis memory. Zero duplicate typing.

7. Compilation & Troubleshooting Recipes

Ensure clean, error-free compilation using recommended build invocations:

Bash / Terminal CompileRecipe.sh 
# Standard 2-pass compilation for TOC & cross-references:
pdflatex -synctex=1 -interaction=nonstopmode PAC1.tex
pdflatex -synctex=1 -interaction=nonstopmode PAC1.tex

# If using BibTeX references:
bibtex PAC1
pdflatex -synctex=1 -interaction=nonstopmode PAC1.tex
pdflatex -synctex=1 -interaction=nonstopmode PAC1.tex

Troubleshooting Tip: Submodule Option Timing

Modules like CMP, MEM, and GNT modify internal document dimensions and package hooks. They must be declared directly in \documentclass[...,CMP]{P3CTeX}, never dynamically loaded later in \PECTeXconfig.
