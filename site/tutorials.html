01 / SETUP

Installation & Environment Setup

P3CTeX is distributed as a packaged TeX tree. You do not need to clone Git repositories to use it in your daily coursework. Once registered in your TeX distribution, \documentclass{P3CTeX} is available system-wide across all your assignments.

  1. Install MiKTeX or TeX Live: Install a standard LaTeX distribution on your computer (MiKTeX on Windows, or TeX Live / MacTeX on Linux/macOS). Enable "Install missing packages on-the-fly".
  2. Download the Release Package: Download P3CTeX-vX.Y.Z.zip from GitHub Releases and extract it to a permanent folder on your system (e.g. C:\LaTeX\P3CTeX or ~/texmf/p3ctex).
  3. Register with your TeX Distribution (One-Time Step):
    • MiKTeX: Open MiKTeX Console → Settings → Directories tab → Click Add → Select the extracted P3CTeX folder → Click Tasks → Refresh file name database (FNDB).
    • TeX Live: Place the files into your personal TEXMFHOME directory or set TEXINPUTS=".:/path/to/p3ctex//:" in your shell.
    • Coursework Directory: Alternatively, you can simply extract the release ZIP directly into your assignment folder next to your .tex file.

Configuring VS Code & LaTeX Workshop for One-Click Compilation

In VS Code with the LaTeX Workshop extension, use this clean build recipe in your settings.json:

JSON settings.json
{
  "latex-workshop.latex.tools": [
    {
      "name": "pdflatex-p3ctex",
      "command": "pdflatex",
      "args": [
        "-synctex=1",
        "-interaction=nonstopmode",
        "-file-line-error",
        "%DOC%"
      ]
    }
  ]
}
02 / PREAMBLE

Preamble Anatomy & UOC Metadata

A compliant P3CTeX document begins with the P3CTeX document class and a single declarative metadata configuration block. This guarantees that all header ribbons, footers, cover sheets, and title bars match official university standards.

LATEX Minimal Compliant Preamble
% Document class with cover, toc, and computer science diagrams enabled
\documentclass[cover,toc,CMP,11pt]{P3CTeX}

% Official Cover Configuration
\PECTeXcover{fullcover, text-uppertitle=PAC 1}

% Academic & Student Identification Data
\PECTeXconfig{
  data = {
    student        = {Dídac Llorens},
    niu            = {0131242},
    grade          = {Grau en Enginyeria Inform\`atica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {Repte 1: An\`alisi L\`exica i Sint\`actica},
    ca-shortname   = {PAC1},
  }
}

\begin{document}
\section{Introducció}
El contingut de la PAC comença aquí...
\end{document}

03 / PAC WORKFLOW

Delivering Continuous Assessment (PAC / PEC)

Continuous assessment activities at UOC require clear structure: statement of each question, explicit methodology, worked calculations, and tabulated comparisons.

Worked Mathematical Calculations with pxCALC

Instead of manually typing error-prone intermediate algebra, pxCALC defines parameters and formats step-by-step arithmetic automatically:

LATEX Mathematical Resolution with pxCALC
\usepackage{pxCALC}

\section{Exercici 1: Càlcul de Rendiment del Sistema}
En aquest exercici calculem la latència mitjana segons el model M/M/1.

\pxDefVar{lambda}{120}[\lambda]  % Taxa d'arribada (req/s)
\pxDefVar{mu}{150}[\mu]          % Taxa de servei (req/s)

\pxDefFormula{tempsW}{1 / ([mu] - [lambda])}[symbol=W, unit=\second]
\pxSolve[steps=true]{tempsW}

Tabulated Comparisons with pxTAB

Produce clean evaluation matrices with zebra striping and custom column headers:

  style           = header-striped,
  headerbgcolor   = blue!15,
  headertextcolor = blue!70!black,
  altrowbgcolor   = gray!10,

04 / PR LABS

Laboratory Implementations & Code Showcases

Laboratory reports (PR) require code excerpts, compiler pipeline representations, and screenshots of execution runs.

Syntax-Highlighted Code with pxLST

P3CTeX provides the \begin{pxCode} environment with dark, pastel, and light themes for all primary computer science languages:

LATEX Java Codebox with pxLST
\usepackage{pxLST}

\pxCodeSet[dark]{pxJava}
\begin{pxCode}[language=pxJava]{ScannerLexer}
public class ScannerLexer {
    private final String source;
    private int cursor = 0;

    public ScannerLexer(String source) {
        this.source = source;
    }

    public Token nextToken() {
        if (cursor >= source.length()) return new Token(TokenType.EOF, "");
        char c = source.charAt(cursor++);
        return new Token(TokenType.CHAR, String.valueOf(c));
    }
}
\end{pxCode}

Resilient Figures with pxSRC

If a teammate or benchmark script hasn't generated a screenshot yet, standard LaTeX halts with a fatal file error. P3CTeX's \pxIMG generates an inline fallback card preserving the exact aspect ratio:

06 / SURVIVAL

"Procrastinar és l'Única Esperança" Emergency Guide

It is 23:45 on submission Sunday. The UOC Virtual Campus deadline is 23:59. Your document refuses to compile. Follow these emergency triage protocols:

TRIAGE // 01

Runaway Compilation Loop

Did pdflatex freeze waiting for user input on error? Terminate with Ctrl + C and always pass non-blocking arguments:

pdflatex -interaction=nonstopmode -halt-on-error main.tex
TRIAGE // 02

Missing Images Halting the Build

Replace broken \includegraphics with \pxIMG. It instantly suppresses missing file exceptions and emits fallback placeholders.

TRIAGE // 03

Table Running Off the Page

If your tabular overflows the margin, switch immediately to \pxTBLlong or set \pxTABsetup{tabwidth=\linewidth} to enforce strict margins.

TRIAGE // 04

Undefined Control Sequence

Missing module package! Check if you used \pxTable without loading pxTAB, or \pxCode without loading pxLST.
