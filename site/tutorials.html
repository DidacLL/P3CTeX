01 / BOOTSTRAP

Installation & Environment Setup (No Git Required)

You don't need to clone development repositories or learn Git internals just to write your coursework. P3CTeX is distributed as a packaged TeX tree. Register it once in your local TeX distribution, and \documentclass{P3CTeX} becomes available everywhere on your computer.

  1. Install MiKTeX or TeX Live: Install a standard LaTeX distribution (MiKTeX on Windows, or TeX Live on Linux/macOS). In MiKTeX, make sure "Install missing packages on-the-fly" is set to Yes.
  2. Download the Release Package: Download P3CTeX-vX.Y.Z.zip from GitHub Releases and extract it to a permanent folder (such as C:\LaTeX\P3CTeX or ~/texmf/p3ctex).
  3. Register with your TeX Engine (One-Time Step):
    • MiKTeX: Open MiKTeX Console → Settings → Directories tab → Click Add → Select your extracted P3CTeX folder → Click Tasks → Refresh file name database (FNDB).
    • TeX Live: Place the files into your personal TEXMFHOME directory or set TEXINPUTS=".:/path/to/p3ctex//:" in your environment.
    • Local Directory Fallback: You can also place P3CTeX.cls and the .sty files directly in the same folder as your document , where LaTeX always finds local class files.
VS Code & LaTeX Workshop One-Click Compilation Setup

For instant Ctrl+S compilation in VS Code, add this build recipe to your settings.json:

}
02 / PREAMBLE

Preamble Anatomy & UOC Metadata

Every assignment starts with \documentclass[options]{P3CTeX} and a single metadata block. Forget copy-pasting messy packages from old semesters: P3CTeX formats the headers, cover, table of contents, and student details automatically.

Key Document Class Options

  • PAC: Continuous assessment in Catalan. Sets up running headers, table of contents, and the official anti-plagiarism declaration.
  • PEC: Continuous assessment in Spanish. Equivalent structure configured for Spanish deliveries.
  • PR: Practical laboratory reports. Automatically includes a formal university cover, table of contents, and list of figures.
  • TFG / MEM: Bachelor Thesis memory. Includes official tribunal assessment sheets, multilingual abstracts, and CC licensing.
  • default: Loads all standard tools (tables, code listings, figure management, UML). No extra \usepackage needed!
  • CMP: Special module for Compilers, Automata, heuristic search graphs ($A^*$), and neural networks.
LATEX Minimal Compliant Preamble
% Document class with PAC profile and default modules loaded
\documentclass[PAC,default]{P3CTeX}

% Academic & Student Identification Data
\PECTeXconfig{
  data = {
    student        = {Estudiant UOC},
    grade          = {Enginyeria Informàtica},
    subj-fullname  = {Compiladors i Llenguatges},
    subj-shortname = {COMP},
    subj-code      = {75.580},
    ca-fullname    = {Repte 1: Anàlisi Lèxica i Sintàctica},
    ca-shortname   = {PAC1},
    date           = {\today}
  }
}
03 / ARCHITECTURE

The Official Shared-Preamble Pattern (Reclaim Your Time)

In a typical UOC semester you have 4 subjects, each with 3 or 4 PACs and 2 PRs. Retyping your name, student ID, subject codes, and bibliography configurations across 20 different documents is a waste of your study time. P3CTeX solves this with a clean 3-tier folder hierarchy:

  1. SharedPreamble.tex (Global): Sits in your root semester folder. Holds your personal student data, degree (Enginyeria Informàtica), anti-plagiarism setting, and custom shortcuts (like \itembf).
  2. MINPreamble.tex (Subject Level): Sits inside each subject folder. Sets the subject name, code, bibliography file, and defines \LoadPreamble{PAC1}{Nom de l'activitat}.
  3. PAC1/MinimalTemplatePAC.tex (Assignment Body): The only file you actually touch! Loads the subject preamble, injects the activity name, and lets you focus 100% on answering the assignment questions.
LATEX PAC1/MinimalTemplatePAC.tex
% Load subject preamble relative to this file
\input{../MINPreamble.tex}

% Inject assignment identifier and full activity title
\LoadPreamble{PAC1}{Anàlisi Lèxica i Sintàctica}

\begin{document}
\section{Exercici 1}
\subsection{Pregunta A}
La resposta a l'exercici es redacta directament aquí.
\end{document}
04 / WORKFLOW

PAC Continuous Assessment Workflow

Continuous assessment submissions require clear answers, structured tables, and illustrative diagrams. With P3CTeX modules loaded via default, you have high-level macros for every task:

1. Tables without tabular boilerplate (pxTAB)

Build tables using comma-separated rows. No manual \hline or column coordinate counting:

LATEX Comma-Separated Table
\pxTable[style=header]{
  Component, Estat, Mètrica
}{
  Lexer (JLex), Complet, 120 tokens/s
}{
  Parser (CUP), Complet, 45 regles
}{
  Generador JVM, Pendent, 0 instruccions
}

2. Resilient figures that never crash builds (pxSRC)

If an image file is missing while compiling under deadline stress, P3CTeX renders a neat placeholder box preserving layout geometry:

LATEX Safe Figure Inclusion
% Inclusió segura d'imatge amb pxSRC
\pxIMG[0.8\linewidth]{img/pipeline}{Pipeline del Compilador}[fig:pipeline]

% Comparativa de dues imatges de costat
\pxIMGpair[0.45\linewidth]{img/ast_initial}{img/ast_optimized}{Arbre Sintàctic abans i després de l'optimització}[fig:ast-comp]

3. Syntax-highlighted code with side comments (pxLST)

LATEX pxCode Listing
\begin{pxCode}[language=pxJava]{Exemple de Factorial}
public class MathUtils {
    public static long factorial(int n) {
        if (n <= 1) return 1;
        return n * factorial(n - 1);
    }
}
\end{pxCode}
05 / ADVANCED

Laboratory Reports (PR) & Bachelor Theses (TFG)

Major milestone deliverables require official covers, multi-chapter memory management, and university assessment criteria.

Practicum Laboratory Reports (\documentclass[PR,default]{P3CTeX})

The PR option automatically generates the full university cover page, table of contents, list of figures, and formatted chapter headers.

Degree Final Theses (\documentclass[TFG,CAT]{P3CTeX})

The TFG and MEM modules provide:

  • Official university tribunal assessment sheet.
  • Multilingual abstract blocks (Catalan, Spanish, English).
  • Creative Commons licensing declaration (CC-BY-SA, CC-BY-NC, etc.).
  • Modular chapter structure using \input{chapters/01_introduction.tex}.
06 / DIAGNOSTICS

Compilation Diagnostics & Common Issues

Solutions to common configuration, font, and package questions when building with P3CTeX:

Error: ! LaTeX Error: File 'P3CTeX.cls' not found

Cause: MiKTeX or TeX Live has not indexed the P3CTeX directory in its database.

Quick Fix (30 seconds): Simply copy P3CTeX.cls and the .sty files directly into the same folder as your assignment .tex file. LaTeX always checks the current folder first!

Permanent Fix: Open MiKTeX Console → Tasks → Refresh file name database (FNDB).

Error: ! Undefined control sequence \pxTombstoneCompile

Cause: The compiler and automata module (pxCMP) was not loaded.

Fix: Add CMP to your document class options: \documentclass[CMP,PAC,default]{P3CTeX}.

Error: Package babel Error: Unknown language 'catalan'

Cause: The Catalan hyphenation and language patterns are missing in your TeX distribution.

Fix: Install texlive-lang-spanish / texlive-lang-european in TeX Live, or in MiKTeX Console install package babel-catalan.
