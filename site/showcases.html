pxCALC: Worked Mathematical Calculations

pxCALC provides variable definition, template formula evaluation, and multi-step worked solutions in pure LaTeX3 (using expl3 fp) without Python or external engines.

KEY FEATURES

• \pxDefVar{name}{value}[symbol] binds variables to math symbols.
• \pxDefFormula{id}{formula}[options] registers formulas with [slot] syntax.
• \pxSolve[steps=3]{id} outputs symbol, formula, substitution, and evaluated result.

SYNTAX HIGHLIGHT

Supports standard arithmetic, fractions (\frac), square roots (\sqrt), trigonometric functions, and SI units (via siunitx).

LaTeX / pxCALC KineticEnergy.tex 
\usepackage{pxCALC}
\pxCalcSetup{prec=2, steps=3}

%% Define physical variables
\pxDefVar{m}{1200}[m]       % Mass in kg
\pxDefVar{v}{25.5}[v]       % Velocity in m/s

%% Define kinetic energy formula
\pxDefFormula{Ek}{\frac{1}{2} * [m] * [v]^2}[symbol=E_k, unit=\joule]

%% Solve with step-by-step substitution:
\[
  \pxSolve{Ek}
\]

pxCMP & pxDIAG: Computation & Compiler Diagrams

pxCMP provides a comprehensive declarative diagramming suite for computer science: Tombstone compiler T-diagrams, finite automata, binary syntax trees, and register maps.

LaTeX / pxCMP DFA_Automaton.tex 
% Declare CMP module on \documentclass:
\documentclass[PAC,default,CMP]{P3CTeX}

\begin{document}
\section{Autòmat Finit Determinista}

\begin{center}
\pxAutomaton[
  preset=p3c-uoc,
  states={
    q0/initial/at={(0,0)},
    q1/middle/at={(2.5,0)},
    q2/accepting/at={(5,0)}
  },
  transitions={
    q0/q1/a,
    q1/q0/b,
    q1/q2/b,
    q2/q2/{a,b}
  }
]{}
\end{center}

\section{Esquema de Compilació Tombstone}
\begin{center}
  \pxTombstoneCompile{App}{C}{x86}{C}
\end{center}
\end{document}

pxLST: Syntax-Highlighted Code Listings

pxLST packages syntax highlighting across 17 languages into rounded, breakable callout boxes with line numbering and JetBrains Darcula palettes.

LaTeX / pxLST CodeBoxExample.tex 
\usepackage{pxLST}
\pxLSTsetup[dark]{pxPython}

\begin{pxCode}[language=pxPython]{Algorisme de Recerca A*}
import heapq

def a_star_search(graph, start, goal, h):
    open_set = []
    heapq.heappush(open_set, (0, start))
    came_from = {}
    g_score = {start: 0}
    
    while open_set:
        _, current = heapq.heappop(open_set)
        if current == goal:
            return reconstruct_path(came_from, current)
            
        for neighbor, weight in graph[current].items():
            tentative_g = g_score[current] + weight
            if tentative_g < g_score.get(neighbor, float('inf')):
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                f_score = tentative_g + h(neighbor)
                heapq.heappush(open_set, (f_score, neighbor))
    return None
\end{pxCode}

pxSRC: Safe Graphics Inclusion & Placeholders

pxSRC intercepts missing figure files and renders a styled placeholder box displaying dimensions and missing file path instead of halting document compilation.

LaTeX / pxSRC SafeFigures.tex 
\usepackage{pxSRC}

%% Safe figure inclusion:
\pxIMG[0.85\linewidth]{img/architecture.png}{Diagrama d'Arquitectura}[fig:arch]

%% Side-by-side comparison pair:
\pxIMGpair[0.48\linewidth]{img/before.png}{img/after.png}{Comparativa abans i després}[fig:comp]

pxMEM: Memory Chapters & Milestone Region Reuse

pxMEM unlocks \chapter support inside the standard article class, enabling modular degree thesis writing where content from prior milestones is injected directly into the final memory.

LaTeX / pxMEM ThesisMemory.tex 
\documentclass[TFG,MEM,CAT,default]{P3CTeX}

\begin{document}
%% Register PR1 milestone deliverable
\pxMEMsource{PR1}{../PR1/PR1.tex}

\chapter{Objectius i Abast del Projecte}
%% Re-use tagged region from PR1 deliverable:
\pxMEMinclude{PR1}{objectius}

\chapter{Arquitectura del Sistema}
Descripció detallada del disseny tecnològic...

\appendix
\pxMEMannex{Especificació de la Base de Dades}{
  Esquema complet en format SQL i diccionari de dades.
}
\end{document}

pxUML: Object-Oriented Class Diagrams

pxUML decouples class metadata from drawing commands, allowing classes to be registered once and rendered cleanly via TikZ.

LaTeX / pxUML ClassDiagram.tex 
\usepackage{pxUML}

\pxUMLClass{Usuari}{- email : String, - passwordHash : String}[+ autentica() : Boolean]
\pxUMLClass{Estudiant}{- expedient : String}[+ matricula() : void]

\pxUMLDiagram*{
  \drawclass[text width=14em]{Usuari}[0,0]
  \drawclass[text width=14em]{Estudiant}[0,-4]
  \inheritance{Estudiant}{Usuari}
}

pxREQ: Requirements Engineering & SWOT Analysis

pxREQ formats User Stories, BDD Given/When/Then scenarios, and SWOT / DAFO business matrices into elegant card containers:

LaTeX / pxREQ RequirementsAndSWOT.tex 
\usepackage{pxREQ}

%% User Story Card:
\begin{pxUserStory}{US-101: Autenticació d'Usuaris}
  \pxAsA{estudiant matriculat}
  \pxIWant{iniciar sessió amb credencials UOC}
  \pxSoThat{puc consultar les meves qualificacions i lliuraments}
  \pxAcceptanceCriteria{
    \begin{itemize}
      \item Error explícit en cas de contrasenya invàlida.
      \item Sessió segura amb renovació periòdica de testimoni JWT.
    \end{itemize}
  }
\end{pxUserStory}

%% Matriu DAFO / SWOT:
\pxDAFO{Alta modularitat expl3, Tipografia cuidada}{Corba d'aprenentatge inicial}{Estandardització docent a la UOC}{Dependències externes de paquets TeX}
