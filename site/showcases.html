pxCMP — Compilers, Automata & AI Diagrams

Taking Compilers or Automata? Drawing state transition tables, lexical validation traces, or Tombstone bootstrapping diagrams in raw TikZ is painful. pxCMP provides clean, high-level declarative macros:

Compiler Tombstones & Bootstrapping

Show source language, implementation language, and target host architecture:

LATEX Tombstone Compilation
% Compilador Java cap a Bytecode JVM executant-se en x86
\pxTombstoneCompile[title={Compilador Java cap a JVM}]{Programa}{Java}{JVM}{x86}

% Bootstrapping d'Oberon de 486 a Pentium-III
\pxTombstoneBootstrap[title={Bootstrapping d'Oberon}]{Oberon}{486}{P-III}

% Arquitectura interna d'un compilador (Front-End / Back-End)
\pxCompilerModel[title={Estructura interna d'un compilador}]

DFA Transition Tables & Traces

Define state machines and word validation traces with formatted verdicts:

LATEX Transition Table & Trace
% Taula de transició d'estats de l'autòmat
\pxTransitionTable[title={Taula de transició del Lexer}]{a, b}{
  q_0 / initial   / q_1, q_2 / I;
  q_1 / normal    / q_3, q_2 / I;
  q_2 / accepting / q_1, q_3 / II;
  q_3 / accepting / q_3, q_3 / II
}

% Traça del reconeixement de la paraula "aba"
\pxAutomatonTrace[title={Traça de la paraula \texttt{aba}}]{
  q_0 / a / q_1; q_1 / b / q_2; q_2 / a / q_1
}[Reconegut]

Heuristic Search Graph ($A^*$)

LATEX pxGraph A* Algorithm
\pxGraph[title={Cerca heurística A*}]{
  A / A / 0,0 / start / $h=20$;
  B / B / 2.2,1.1 / path / {$g=4, f=16$};
  C / C / 2.2,-1.1 / visited / $h=15$;
  G / G / 4.4,0 / goal / $h=0$
}{
  A => B / 4; A -> C / 5; B => G / 8; C -> G / 12
}

pxTAB — Multipage Tables Without The Headache

Tables in LaTeX are notoriously tedious. pxTAB lets you build professional tables by just listing rows separated by commas. No manual column specifications, automatic zebra striping, and dedicated support for multipage tables:

Declarative Comma-Separated Table & Presets

No raw tabular code, no manual column specifications, and automatic zebra striping:

LATEX pxTable with p3c-data Preset
% Aplicar preset de dades amb ratlles alternes (zebra)
\pxTABusepreset{p3c-data}

\pxTable{
  Mòdul, Descripció, Estat, Temps
}{
  pxSRC, Inclusió resilient de figures, Actiu, 0.05 ms
}{
  pxTAB, Generació declarativa de taules, Actiu, 0.12 ms
}{
  pxLST, Caixes de codi amb ressaltat, Actiu, 0.45 ms
}{
  pxCMP, Diagrames d'enginyeria informàtica, Actiu, 1.20 ms
}

Huge Multipage Table with Repeated Running Headers

Automated Image Lists & Batch Iteration

Have 10 step-by-step screenshots from a laboratory VM? Don't write 10 repetitive \begin{figure} blocks. \pxIMGList generates numbered figure sequences from a list of captions automatically:

Built-in Sequential Image Lists

Renders results_1.png, results_2.png, etc., with safe labels automatically:

LATEX pxIMGList Sequential Macro
% Carrega automàtica de results_1, results_2, results_3
\pxIMGList[0.8\linewidth]{results_}{
  Primer pas: Captura d'imatge en cru,
  Segon pas: Filtratge Sobel per contorns,
  Tercer pas: Binarització i segmentació
}

Automated Benchmark Loop

LATEX Loop Over Test Vectors
% Iteració amb \foreach sobre vectors de prova
\pxTable{ID Prova, Entrada, Resultat}{
  \foreach \id/\str/\res in {
    T1/\texttt{x = 42;}/ASSIGN,
    T2/\texttt{while(true)}/LOOP,
    T3/\texttt{return 0;}/EXIT
  }{
    \id, \str, \res \par
  }
}

pxLST — Professional Code Listings & Themes

Make your algorithms look like modern IDE editors. pxLST supports 16 languages, Darcula dark frames, and side-note comment boxes for explaining complex code:

Syntax Highlighted pxCode

LATEX pxCode with Darcula Style
% Activar paleta dark
\pxLSTpalettedark

\begin{pxCode}[language=pxJava]{Fibonacci Recursiu}
public class Fibonacci {
    public static int fib(int n) {
        if (n <= 1) return n;
        return fib(n - 1) + fib(n - 2);
    }
}
\end{pxCode}

Side-Comment Annotated CodeBox

LATEX CodeBox with Side Notes
\begin{CodeBox}{lst-alg}{Factorial Iteratiu}{[alg-01]}{Càlcul iteratiu de complexitat O(n).}
Funcio factorial(n: Integer): Integer
  Si n <= 0 Llavors
    Retornar 1
  Sinó
    resultat <-- 1
    Per i = 1 A n Fer
      resultat <-- resultat * i
    Fi Per
    Retornar resultat
  Fi Si
Fi Funcio
\end{CodeBox}
