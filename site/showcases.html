MOD // 01 pxCMP — Compilers, Automata & AI Diagrams

The pxCMP module provides declarative macros to generate Tombstone (T-diagrams) for compilers, finite state transition tables, execution traces, heuristic search graphs, and neural networks.

pxCMP // TOMBSTONE

Compiler T-Diagrams

Represent source languages, implementation languages, and target host architectures:

LATEX Tombstone Compilation
% Compile Java to JVM Bytecode using an x86 compiler
\pxTombstoneCompile[title={Compilador Java cap a Bytecode JVM}]
  {Programa}{Java}{JVM}{x86}

% Bootstrapping an Oberon compiler from 486 to Pentium-III
\pxTombstoneBootstrap[title={Bootstrapping d'Oberon}]
  {Oberon}{486}{P-III}
pxCMP // AUTOMATA

DFA Transition Tables & Traces

Define state machines and word validation traces with formatted verdicts:

LATEX Transition Table & Trace
% Taula de transició d'estats
\pxTransitionTable[title={Taula de transició del Lexer}]{a, b}{
  q_0 / initial   / q_1, q_2 / I;
  q_1 / normal    / q_3, q_2 / I;
  q_2 / accepting / q_1, q_3 / II;
  q_3 / accepting / q_3, q_3 / II
}

% Traça del reconeixement de la paraula "aba"
\pxAutomatonTrace[title={Traça de la paraula \texttt{aba}}]{
  q_0 / a / q_1; q_1 / b / q_2; q_2 / a / q_1
}[Rebutjat]

BLOB // 03 Recursive & Iterative Executions with \foreach

Eliminate copy-paste repetition. Using LaTeX's PGF/TikZ \foreach engine, you can generate batch image galleries, automated test case tables, and benchmark comparisons with a single loop.

LOOP // SUBFIGURES

Batch Subfigure Iteration

LATEX Automated Image Gallery
% Generació automàtica de 4 figures de benchmarks
\noindent\foreach \idx/\nomFiltre in {
  1/Original,
  2/Filtre-Sobel,
  3/Binaritzat,
  4/Contorns-Finals
}{%
  \begin{minipage}[t]{0.48\linewidth}
    \centering
    \pxIMG[0.9\linewidth]{results/step_\idx}{\nomFiltre\ (Pas \idx)}[fig:pas_\idx]
    \vspace{1em}
  \end{minipage}%
  \hfill\ifnum\idx=2 \par\vspace{1em}\fi
}
LOOP // TEST MATRIX

Automated Benchmark Runner Loop

LATEX Loop Over Test Vectors
% Iteració sobre vectors de prova del lexer
\pxTABsetup{style=striped, tabwidth=\linewidth}
\pxTable{ID Prova, Cadena d'Entrada, Resultat Esperat}{
  \foreach \id/\str/\res in {
    T1/\texttt{x = 42;}/ASSIGN,
    T2/\texttt{while(true)}/LOOP,
    T3/\texttt{return 0;}/EXIT
  }{
    \id, \str, \res \par
  }
}

MOD // 04 pxLST — Professional Codeboxes & Themes

Syntax highlighting with custom color themes (dark, pastel, light) and line numbering for Java, Python, C++, Bash, SQL, and pseudocode.

THEME // DARK

Java Snippet in Dark Theme

LATEX Dark Style pxLST
\pxCodeSet[dark]{pxJava}
\begin{pxCode}[language=pxJava]{Fibonacci}
public class Fibonacci {
    public static int compute(int n) {
        if (n <= 1) return n;
        int a = 0, b = 1;
        for (int i = 2; i <= n; i++) {
            int tmp = a + b;
            a = b; b = tmp;
        }
        return b;
    }
}
\end{pxCode}
THEME // FRAMED PASTEL

Iterative Algorithm in Pastel Frame

LATEX Framed CodeBox
\pxCodeSet[pastel]{algoritme}[framed]
\begin{CodeBox}{lst-alg}{Algorisme: Factorial}{[lst:fact]}{Càlcul iteratiu}
Funcio factorial(n: Integer): Integer
  Si n <= 0 Llavors
    Retornar 1
  Sino
    res <-- 1
    Per i = 1 A n Fer
      res <-- res * i
    Fi Per
    Retornar res
  Fi Si
Fi Funcio
\end{CodeBox}

MOD // 08 pxUML — Object-Oriented Class Modeling

Declare classes, attributes, methods, inheritance, and associations cleanly, separating data models from visual placement.

LATEX Object-Oriented UML Modeling
% 1. Definició de classes i mètodes
\pxUMLClass{Persona}{- nom : String}[+ getNom() : String]
\addAttribute{Persona}{- edat : Integer}
\addOperation{Persona}{+ setNom(nouNom : String) : void}

% 2. Classes derivades i herència
\pxUMLClass{Estudiant}{- niu : Integer}[+ lliurarPAC() : void]
\addInheritance{Estudiant}{Persona}

% 3. Renderització del diagrama
\pxUMLDiagram{
  \drawclass[text width=14em]{Persona}[0,0]
  \drawclass[text width=14em]{Estudiant}[0,-4]
}[0.85\linewidth]
