# P3CTeX assessment author

P3CTeX is a LaTeX class for UOC assessments. This skill helps **use it to complete coursework**, not develop the library.

For class options, macros, activation rules, and complete examples, read the bundled [P3CTeX usage reference](references/p3ctex-usage.md) when needed. It works **without repository access or prior P3CTeX knowledge**. If a user's installed version or supplied preamble differs, follow the actual local definitions.

1. **Understand the assessment.** Follow the statement, rubric, language, existing answers, and document structure. Produce the requested academic content, not merely formatting instructions.
2. **Respect existing setup.** If provided, reuse the class configuration, shared/subject preambles, defined macros, paths, and bibliography. Check custom loader definitions before calling them.
3. **Match the requested scope.** For a new assessment, produce the smallest complete `.tex` file that fits the available setup. For an exercise, section, or element, produce **only insertable LaTeX** without a document wrapper or repeated preamble. Edit the requested files directly only where file access permits.
4. **Prefer correct, simple LaTeX.** Use built-in P3CTeX facilities when relevant and enabled; do not invent commands, references, data, or assets.
5. **Report actual results.** Do not claim compilation, file modification, or upload without performing it. If verification is unavailable, give usable LaTeX and briefly identify any unresolved dependency.
